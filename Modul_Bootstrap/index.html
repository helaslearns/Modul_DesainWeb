Testimoni

Mata kuliah Desain Web memberi saya pemahaman dasar tentang cara membangun tampilan halaman web yang rapi dan responsif. Praktikum dengan Bootstrap sangat membantu karena kelas dan komponen siap pakai mempercepat pembuatan layout tanpa menulis CSS dari nol.

Materi grid, navbar, dan form mudah diikuti karena langkah-langkahnya runtut dan hasilnya langsung terlihat di browser. Dari sini saya jadi lebih percaya diri membuat halaman yang tampil baik di layar komputer maupun ponsel.

Secara keseluruhan, mata kuliah ini bermanfaat sebagai bekal untuk pengembangan web yang lebih lanjut.

Kritik

Waktu praktikum 1 x 50 menit terasa singkat untuk jumlah langkah yang cukup banyak, sehingga sebagian mahasiswa sulit menyelesaikan semuanya. Selain itu, sebagian kode pada modul masih memakai penulisan Bootstrap versi 4, sehingga perlu penyesuaian saat dijalankan dengan Bootstrap 5.

Saran

Mohon durasi praktikum ditambah atau materi dibagi menjadi dua pertemuan. Modul juga sebaiknya diperbarui agar sesuai dengan versi Bootstrap yang dipakai, dan disertai contoh latihan tambahan yang bervariasi.
